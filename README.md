**What is currently working ?** 

We have all of our main data structures implemented. We have circular buffers for history storage, we have a AVL BST for leaderboards, and we have prefix trees for player searching, along with a few more.

Running the server:

1). Compile server in /game_server simply 
```
cd game_server
make
```
2).  Run server
```
cd platfrom_server
python server.py
```
3). Run client
```
python test_game_launcher.py
```
This is just a test client to launch games and manage ports not our full client
